# Historical ReFind 0.2.0 release artifacts

The historical `ReFind_0.2.0_UX01.zip` is generated by `python tools/build-release.py --batch UX01`. The verified B06 archive remains a historical checkpoint.

The archive includes the runnable application, actual SQL/reference seed, non-destructive setup/demo tools, licensed local assets, editable draw.io artefacts/exports and academic verification evidence. Runtime storage, local configuration, credentials, database backups, node_modules and mutation-test helpers are excluded. New credentials/media are generated by setup/seeding on the destination.

Adjacent `.manifest.json` records ZIP/file/runtime hashes and exclusion checks; `.verification.json` ties actual fresh-install acceptance to the exact archive. This directory is denied over HTTP; open the ZIP locally.

Current v0.2.5 release-readiness delivery is the reviewed Git branch/draft PR. These archives and receipts were not regenerated for that work. Use the current installation guide and audit report, not these historical ZIPs, for release status.
